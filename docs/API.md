# OncoNova AI API reference

Generated by `make report` from the live OpenAPI schema (`docs/openapi.json`). Interactive docs: `http://127.0.0.1:8010/docs` while the API is running.

> Research and educational prototype. Not a medical device. Not for diagnosis, treatment planning or any clinical decision. No endpoint controls, configures or communicates with medical equipment.

**Conventions**

- Auth: in `dev` mode, localhost only; in `api_key` mode send `X-API-Key`. Roles: viewer < researcher < admin.
- Errors: `{"error": {"code", "message", "details"}, "request_id"}`. No stack traces are returned.
- Missing inputs return HTTP 200 with `{"status": "unavailable", "reason", "missing_inputs", "how_to_fix"}`, never a guess.
- Binary volumes: raw little-endian arrays (C order, z-y-x) with `X-Shape`, `X-Spacing`, `X-Origin`, `X-Direction`, `X-Dtype`, `X-Scale`, `X-Offset` headers; value = raw x scale + offset.
- Lesion sources: `reference`, `annotation`, or `pred:<model_id>`.

## System

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/health` | Liveness probe. No authentication; returns no data. |
| `GET` | `/api/system` | Version, safety statements, auth mode, model status and data counts. |
| `GET` | `/api/evaluations` | Measured evaluation reports written by the evaluation scripts. Empty if none have been run. |
| `GET` | `/api/evaluations/{report_id}` | One full evaluation report. |
| `GET` | `/api/datasets` | Public dataset catalogue (verified fields, with 'not stated' where unverified) and local manifests. |
| `GET` | `/api/audit` | Most recent audit events (admin only). Contains identifiers and actions, never image data. |
| `GET` | `/api/settings/deid-profile` | The active DICOM de-identification profile (configs/deid_profile.yaml or the built-in default). |

**`GET /api/evaluations/{report_id}`**
- `report_id` (path, string, required)

**`GET /api/audit`**
- `n` (query, integer)

## Cases

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/cases` | List all cases (demo and uploaded) with their timepoints. |
| `GET` | `/api/cases/{case_id}` | Full case record: timepoints with geometry, reference/structure availability, provenance. |
| `DELETE` | `/api/cases/{case_id}` | Permanently delete an uploaded case and all derived results. Demo cases cannot be deleted. |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/image` | Image voxels as int16 with geometry headers (see onconova.api.binary). |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/maps/{kind}` | Overlay volumes on the image grid: label maps as uint8, continuous maps quantised to uint8.  ``prediction``/``uncertainty``/``saliency`` need ``model_id``; ``dose`` needs ``key`` (from a dose result). |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/metadata` | Geometry and de-identified technical metadata. Identifying fields are reported by name only. |
| `PUT` | `/api/cases/{case_id}/timepoints/{tp_id}/annotation` | Save a manual annotation: raw uint8 body, C order, image shape, values 0-3 (lesion classes). |
| `DELETE` | `/api/cases/{case_id}/timepoints/{tp_id}/annotation` | Delete the manual annotation for this timepoint. |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/mesh` | Surface mesh (LPS mm) for 3-D display. ``source``: reference, annotation, pred:<model> or structures. |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/registered` | This timepoint resampled into the baseline frame after rigid registration (for side-by-side review). |
| `POST` | `/api/uploads` | Upload one volume as the raw request body: .nii / .nii.gz (pass ``modality``) or a .zip of one DICOM series.  The filename is used only to detect the format and is never stored. DICOM is de-identified before parsing; only the converted volume and de-identified metadata are kept. |

## Analysis

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/models` | Segmentation and progression models with status, model card and provenance. |
| `POST` | `/api/cases/{case_id}/timepoints/{tp_id}/segmentation` | Run a segmentation model on one scan. Returns lesion list, volumes, uncertainty and warnings. |
| `GET` | `/api/cases/{case_id}/timepoints/{tp_id}/segmentation` | Most recent stored segmentation summary, or an explicit unavailable state. |
| `POST` | `/api/cases/{case_id}/timepoints/{tp_id}/comparison` | Agreement between a model prediction and the reference or manual annotation (Dice, IoU, HD, HD95, ...). |
| `POST` | `/api/cases/{case_id}/longitudinal` | Register follow-ups to baseline and quantify observed lesion changes (no prediction). |
| `GET` | `/api/cases/{case_id}/longitudinal` | Stored longitudinal result for a lesion source, or an unavailable state. |
| `POST` | `/api/cases/{case_id}/progression` | Estimate the (simulated) future-progression outcome, with interval, or return why it is unavailable. |
| `GET` | `/api/progression/model` | Progression model card, including its outcome definition, horizon, features and limitations. |
| `GET` | `/api/dose/scenarios` | Hypothetical beam-arrangement scenarios for the geometric illustration. |
| `POST` | `/api/cases/{case_id}/dose` | Compute the SIMULATED, NON-CLINICAL geometric dose illustration and its DVHs (relative units). |
| `GET` | `/api/cases/{case_id}/dose` | Stored dose illustration for a scenario, or an unavailable state. |
| `GET` | `/api/cases/{case_id}/dose/beams` | Per-beam shares of the SIMULATED illustration on the axial slice through the target (n_beams, y, x). |
| `POST` | `/api/cases/{case_id}/dose/import` | Import a research dose grid (DICOM RTDOSE or NIfTI) as the raw body; shown as stored, never verified. |
| `GET` | `/api/cases/{case_id}/summary` | Research summary, sections A-G, each item tagged measured / model output / uncertain / expert review. |
| `GET` | `/api/cases/{case_id}/results` | Names and timestamps of every stored result for this case. |
